 # Thompson

АІ-асистент, що працює переважно локально (офлайн, дані на пристрої), розмовляє та пише повідомлення українською мовою і підтримує системах Linux та Windows.

![build](https://github.com/rub1-618/thompson-app/actions/workflows/build.yml/badge.svg)

Англійська версія файлу README міститься у файлі README.md.

# Функції:
- Голосовий ввід/вивід із командою пробудження «Том». Має офлайн-розпізнавання мови (whisper), VAD
- TTS: espeak-ng (Linux) / SAPI (Windows)
- АІ-асистент-чат із перемиканням одним кліком між Ollama (локальний) та Gemini API (хмарний).
- Аналіз екрану за допомогою Gemini Vision.
- Команди керування музикою: MPRIS (Linux) / GSMTC + мультимедійні клавіші (Windows)
- Команди для перегляду статистики ЦП/ОЗУ/температури, нагадування, диктування та власні команди!

# Вимоги: 
- Ollama + модель (локальний ШІ); 
- модель Whisper, наприклад: ggml-base.bin (голос); 
- ключ API Gemini (хмарний сервіс / обробка зображень); 
- WebView2 (Windows).

# Встановлення (готова збірка)
Ви можете встановити готову збірку з GitHub Actions -> artifacts / release; 
- Linux — chmod +x ... && ./...AppImage (а також > --appimage-extract-and-run без FUSE); 
- Windows — .msi.

# Встановлення (збірка з вихідного коду)
```bash
> cargo install tauri-cli --version "^2.0"
> cargo run                                 # dev
> cargo tauri build --bundles appimage      # Linux
> cargo tauri build --bundles msi           # Windows
```
P.S.: якщо ви користуєтеся Arch, вам слід використовувати саме цей:
```bash
> NO_STRIP=1 cargo tauri build --bundles appimage
```
# Використання:
| команда | що робить |
| --- | --- |
| "котра година" | повідомляє поточний час і дату |
| "аналіз екрану" | запускає аналіз екрану за допомогою Gemini Vision |
| "стоп музику / відтвори" | вмикає/вимикає відтворення музики у вашому плеєрі |
| "наступний трек" | переходить до наступної пісні у вашому плеєрі |
| "попередній трек" | повертає до попередньої пісні у списку відтворення |
| "нагадай мені через ... хвилин про ..." | встановлює нагадування та повідомляє, коли час настане |
| "відкрий браузер" | відкриває сторінку Google у браузері |
| "напиши '...'" | вводить вказану фразу |
| "стоп" | зупиняє відповідь, навіть якщо він говорить |

# Дані та налаштування:
